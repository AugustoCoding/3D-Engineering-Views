# Segurança

A maquete é um HTML estático: não tem servidor, login nem dado de usuário.
Mesmo assim, se você achar um problema de segurança — no HTML publicado, no
workflow do GitHub Pages ou numa dependência —, relate **em particular**:

**Security → Report a vulnerability**, nesta página do repositório.

Não abra issue pública para isso. A versão que vale é a da branch `main`
(a que está no ar).
